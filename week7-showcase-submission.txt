SHOWCASE ITEM 1
Title: QBR Data Layer for a Copilot Agent, internship at Veeam (agent architecture is confidential and not shown)
Bottom line: CSMs spent up to a week assembling each client QBR, so I built the data layer that lets a Teams Copilot agent generate one on demand. It's now used by 500+ employees.
Your role: Team of 2. I led the build and owned the SQL data layer; my teammate handled reviews.
Approach: I unified the lakehouse and ServiceNow data into one query layer instead of letting the agent query each source separately. Outcome: Deployed to 500+ employees, saving an estimated 7,000+ hours of QBR building annually across CSMs.
